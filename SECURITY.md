# Security Policy

## Supported Versions

Currently, only the latest release of Flo is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Flo, please DO NOT open a public issue. 

Instead, please send an email to the repository owner directly. We will treat your report with the utmost priority and work to resolve the issue promptly.
